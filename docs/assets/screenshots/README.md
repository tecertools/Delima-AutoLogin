# Panduan Memuat Naik Gambar Tangkapan Skrin (Screenshot Guide)

Folder ini digunakan untuk menyimpan gambar tangkapan skrin sebenar bagi laman tutorial interaktif **DELIMa Smart Launcher**.

Laman tutorial telah diprogramkan untuk mengesan dan memaparkan imej-imej ini secara automatik sekiranya fail dengan nama di bawah dimuat naik. Jika belum dimuat naik, laman web akan memaparkan *placeholder* visual yang cantik dengan panduan grafik.

## Petua Mengambil Tangkapan Skrin yang Jelas:
1. Gunakan alat **Snipping Tool** bawaan Windows (`Win + Shift + S`).
2. Simpan dalam format **PNG** untuk ketajaman teks yang terbaik.
3. Pastikan tiada data peribadi murid sebenar (cth: MyKid atau Nombor Telefon peribadi) terdedah secara terbuka — gunakan data contoh ujian sekolah.
