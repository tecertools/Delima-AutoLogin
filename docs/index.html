Fasa 1: Persediaan Awal

Keperluan Sistem & Senarai Semak Peralatan

🖥️ Semua Komputer

Sebelum memulakan pemasangan, pastikan anda telah menyediakan perkakasan, perisian, dan fail data murid yang mencukupi bagi melancarkan proses persediaan.

  • A
    PC Pentadbir (Komputer Guru Penyelaras ICT)
    Komputer riba atau desktop dengan Windows 10 (versi 1809 ke atas) atau Windows 11 (64-bit). Digunakan sekali sahaja untuk membina pakej konfigurasi sekolah menggunakan aplikasi Delima.Admin.exe.
  • B
    PC Makmal Komputer (Komputer Murid)
    Komputer makmal yang menggunakan Windows 10/11 x64 dengan pelayar Google Chrome atau Microsoft Edge terpasang. Komputer makmal mestilah mempunyai akaun murid biasa (*Standard User*) serta hak pentadbir (*Administrator*) sementara untuk proses *provisioning*.
  • C
    Pemacu Kilat USB (Pendrive)
    Satu pemacu USB kosong dengan saiz sekurang-kurangnya 1GB berformat FAT32 atau NTFS untuk memindahkan pakej sulit school.dlmpack ke PC makmal.
  • D
    Fail Data Murid & Kata Laluan DELIMa
    Fail CSV senarai nama murid sekolah serta senarai kata laluan DELIMa murid yang disediakan oleh pihak sekolah.

    Lengkapkan Pemasangan
    Tekan Next dan biarkan direktori pemasangan lalai di C:\Program Files\DELIMa Launcher. Klik Install sehingga selesai.

Import Senarai Murid & Pemetaan Lajur

Muat naik fail CSV senarai murid dan sahkan pemetaan lajur data.

    Semak Laporan Percubaan (Dry-Run Validation Report)
    Pastikan penunjuk status menunjukkan hijau: Semua Rekod Sah & Sedia. Sekiranya terdapat amaran murid bertindih atau ID tidak lengkap, baiki fail CSV berkenaan.

Import senarai kata laluan DELIMa murid yang akan disulitkan secara serta-merta dengan enkripsi gred tentera AES-256-GCM.

Fasa 4: Penyeragaman Makmal

Menjalankan Penyediaan di Setiap PC Makmal (Delima.Provision)

⚡ Proses Cepat (1 Minit/PC)

Bawa pemacu USB ke komputer murid di makmal untuk memindahkan dan mengunci pangkalan data ke perkakasan setiap PC.

  • 1
    Cucuk USB ke PC Makmal & Jalankan Delima.Provision
    Log masuk sebagai akaun Administrator di PC makmal. Buka pemacu USB, klik kanan pada Delima.Provision.exe dan pilih "Run as administrator".
  • 2
    Pilih Pakej & Masukkan Kata Laluan Pentadbir
    Pilih fail school.dlmpack dan taipkan Kata Laluan Pentadbir yang telah anda tetapkan di Langkah 5.
  • 3
    Penguncian Perkakasan Automatik (DPAPI Binding)
    Alat ini akan menyahsulit pakej dan menyimpan fail credentials.dat di dalam %ProgramData%\DELIMa Launcher\, kemudian menguncinya terus ke cip perkakasan komputer berkenaan menggunakan Windows Data Protection API (DPAPI Skop Mesin). Fail ini tidak boleh disalin ke PC lain.
  • 4
    Ulang pada PC Seterusnya
    Cabut pemacu USB dan ulang proses ini pada komputer makmal yang lain. Keseluruhan proses hanya mengambil masa kurang daripada 1 minit bagi setiap PC!
PowerShell (Pilihan Pantas Melalui Command Line): 
# Jalankan di PowerShell Pentadbir (gantikan E: dengan huruf pemacu USB anda)
E:\Delima.Provision.exe --pack E:\school.dlmpack

Ujian Keselamatan Storan & Pengukuhan AppLocker (Pilihan)

🛡️ Ujian Sekatan Fail

Lakukan ujian pengesahan keselamatan untuk memastikan akaun murid biasa tidak dapat membaca atau menyalin fail kelayakan makmal.

  • 1
    Ujian Sekatan Hak Akses (*Access Denied Test*)
    Log keluar daripada akaun pentadbir dan log masuk sebagai akaun Murid biasa. Tekan Win + R, taipkan arahan di bawah dan tekan Enter:
Ujian Membuka Fail Storan Menggunakan Notepad: 
notepad "C:\ProgramData\DELIMa Launcher\credentials.dat"

Keputusan Yang Dikehendaki: Notepad mestilah memaparkan dialog ralat "Access is denied" (Akses Ditolak). Ini membuktikan senarai kawalan capaian NTFS (ACL) berfungsi sepenuhnya melindungi data murid.

  • 2
    Pengukuhan Tambahan Melalui AppLocker (Disyorkan)
    Bagi makmal dengan Windows Enterprise atau Education, jalankan skrip pengukuhan AppLocker untuk menghalang murid daripada menjalankan fail program luaran daripada pemacu USB atau direktori Temp.
Skrip Pengaktifan AppLocker (Administrator PowerShell): 
# Pastikan perkhidmatan Application Identity berjalan
Set-Service -Name "AppIDSvc" -StartupType Automatic
Start-Service -Name "AppIDSvc"

Penyelenggaraan Tahunan, Murid Baharu & Soalan Lazim (FAQ)

📚 Panduan Sokongan

Panduan lengkap untuk mengurus murid berpindah masuk/keluar, pertukaran sesi persekolahan baharu, dan penyelesaian masalah lazim.

Soalan Lazim & Senario Biasa (FAQ)

Q1
Bagaimana jika ada murid baharu berpindah masuk ke kelas?
Buka Delima.Admin.exe pada PC Guru, import fail senarai CSV terkini (atau tambah rekod murid baharu), jana pakej school.dlmpack baharu ke Pendrive USB, dan jalankan Delima.Provision.exe pada PC makmal. Data lama akan digantikan secara lancar.
Q2
Bagaimana jika kata laluan DELIMa murid diubah di portal KPM?
Ulang proses import fail kata laluan baharu di Delima.Admin.exe, eksport pakej ke USB, dan jalankan Delima.Provision.exe pada PC makmal untuk mengemas kini storan selamat.
Q3
Adakah pelayar Chrome atau Edge yang lebih disyorkan?
Kedua-dua pelayar Microsoft Edge dan Google Chrome disokong sepenuhnya dengan ketepatan 100%. Pemasang DELIMa Launcher secara automatik melumpuhkan dialog pengurus kata laluan (*Password Manager popup*) pada kedua-dua pelayar.
Q4
Bagaimana jika skrin monitor makmal menggunakan resolusi lama (1366x768)?
Antaramuka DELIMa Smart Launcher direka bentuk mengikut piawaian penskalaan dinamik WPF dan diuji pada resolusi serendah 1366x768 sehingga skrin sentuh 4K tanpa sebarang masalah teks terpotong.
